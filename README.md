# 高校课程项目协作与评审平台 V4.0

本目录为依据需求分析报告完善后的 V4.0 可提交、可运行、可编译完整项目文件。V4 保持 Flask + SQLite + 原生 JavaScript + Electron 技术框架不变，补齐课程、团队协作、过程检查、互评预警和成绩复核闭环。

## 提交材料

- `1、环境清单.txt`：运行、测试和打包环境要求。
- `backend/`、`frontend/`、`desktop/`：完整系统源码。
- `3、系统说明.txt`：系统功能、技术结构、角色权限和运行方法。

## 快速开始

双击根目录中的 `启动系统.bat`：

1. 选择 `1` 启动网页版，访问 `http://127.0.0.1:5080`。
2. 选择 `2` 启动 Electron 桌面版。
3. 选择 `3` 安装全部依赖。
4. 选择 `4` 检查环境。
5. 选择 `5` 运行测试。
6. 选择 `6` 构建 Windows 便携版。

演示账号统一密码：`123456`。

V4 演示角色：教务管理员、教师、助教和学生。新增项目草稿、多迭代管理、入队审批、成员任务、助教查收/退回/催交、三维匿名互评、异常评分预警、成绩申诉与复核、登录失败锁定和定时截止提醒。

## 目录

- `backend/`：Flask API、SQLite 数据、上传文件和 pytest 测试。
- `frontend/`：登录页、工作台和全部业务页面。
- `desktop/`：Electron 主进程、依赖锁定文件和打包脚本。
- `docs/`：设计稿、运行效果图、需求差距和开发参考资料。
- `tools/`：启动菜单与统一运行逻辑；根目录仍只保留一个 `.bat`。

桌面依赖目录 `desktop/node_modules` 属于可再生成缓存，不包含在提交文件中；运行 `npm install` 会严格按照 `package-lock.json` 还原依赖。

3、系统说明

系统名称：高校课程项目协作与评审平台
提交版本：V4.0
项目目录：Course_platform_v4

一、系统概述

本系统面向高校课程项目教学，覆盖项目发布、学生组队、多轮迭代提交、匿名同伴互评、助教过程评分、教师终评、成绩发布、成绩复核、通知提醒和操作审计等完整业务环节。系统同时提供网页版和 Electron 桌面版，前后端与桌面端源码均包含在本项目目录中。

二、主要技术

1. 前端：HTML5、CSS3、原生 JavaScript 单页应用。
2. 后端：Python、Flask、SQLite、Waitress。
3. 桌面端：Electron、Node.js、electron-builder。
4. 数据导出：openpyxl 生成 Excel 成绩文件。
5. 测试：pytest 后端自动化测试、Node.js 前端语法检查。

三、核心功能

1. 教师创建课程，保存项目草稿，设置多轮迭代、截止时间与评分权重后正式发布。
2. 学生创建团队、申请加入，由组长审批；教师可执行带理由的成员例外调整。
3. 组长按迭代为成员分配个人任务，成员更新任务状态，负责人或指定成员提交成果。
4. 支持 PDF、ZIP、MP4 文件上传、历史版本、撤回、退回修改、助教查收和并发版本校验。
5. 助教按迭代录入过程检查分，批量查看未提交团队并一键发送催交通知。
6. 匿名互评包含完成度、创新性和文档质量三个维度，支持草稿、极值剔除和异常评分预警。
7. 教师录入终评分并核定个人系数与扣分，系统自动计算团队与个人成绩。
8. 成绩发布后生成不可变快照，支持撤回、学生申诉、教务复核和 Excel 归档导出。
9. 发布、组队、审批、提交、互评、评分、复核和导出等关键操作均写入审计日志。
10. 连续五次登录失败自动锁定账号 15 分钟，关键截止时间自动生成站内提醒。

四、角色与权限

教务管理员：全局查看课程项目、处理成绩复核、撤回发布、导出归档和审计查询。
教师：项目管理、互评控制、终评分、个人成绩核定、成绩发布与导出。
助教：查看团队与成果、按迭代查收或退回、录入过程分、催交和处理互评预警。
学生：申请或审批入队、参与任务分工、提交成果、完成匿名互评、查看并复核个人成绩。

五、目录结构

backend      Flask 后端、SQLite 数据、上传文件与自动化测试
frontend     登录页、工作台、业务页面、样式与运行图片资源
desktop      Electron 桌面端源码、依赖锁定文件与打包脚本
docs         设计稿、运行效果图、提示词、需求差距和历史开发说明
tools        PowerShell 中文菜单和统一启动逻辑
1、环境清单.txt      运行与编译环境要求
3、系统说明.txt      本说明文件
启动系统.bat         唯一批处理入口，调用 tools\launcher.ps1
README.md            项目快速说明

六、启动方法

1. 双击项目根目录中的“启动系统.bat”。
2. 输入 1 启动网页版，浏览器将打开 http://127.0.0.1:5080 。
3. 输入 2 启动桌面版；首次运行会自动安装缺失的 Electron 依赖。
4. 输入 3 可安装或更新全部 Python、Node.js 依赖。
5. 输入 4 可检查本机环境，输入 5 可运行项目测试，输入 6 可构建桌面便携版。
6. 运行期间请保持启动窗口开启。

十、注意事项

1. desktop\node_modules 不随提交文件保存，首次运行桌面版时通过 package-lock.json 安装锁定版本依赖。
2. 不要删除 frontend\assets 中的图片，它们是登录界面运行资源。
3. 若 5080 端口被占用，请先关闭旧的本地服务后再启动。
4. 提交或迁移系统时，应完整保留 backend、frontend、desktop、docs 及根目录说明文件。

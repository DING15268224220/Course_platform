3、系统说明

系统名称：高校课程项目协作与评审平台
系统版本：最终版

一、系统概述

本系统面向高校课程项目教学，覆盖课程项目发布、学生组队、任务分工、迭代成果提交、助教过程检查、匿名同伴互评、教师评分、成绩发布、成绩复核、通知提醒和操作审计等业务环节。系统提供网页版和 Electron 桌面版，并按照教务管理员、教师、助教和学生四类角色进行权限控制。

二、技术架构

1. 前端：HTML5、CSS3、原生 JavaScript。
2. 后端：Python、Flask、Waitress。
3. 数据存储：SQLite。
4. 桌面端：Electron、Node.js、electron-builder。
5. 数据导出：openpyxl、ReportLab。
6. 自动化测试：pytest、Playwright、Chromium。

三、功能模块

1. 课程与项目管理
   支持课程创建、项目草稿、项目发布、多轮迭代、截止时间和评分权重设置。

2. 团队与成员管理
   支持学生创建团队、申请入队、组长审批、成员调整以及按迭代分配个人任务。

3. 成果提交与版本管理
   支持 PDF、ZIP、MP4 文件上传、历史版本查询、成果撤回、查收和退回修改。系统在提交时校验团队人数、迭代截止时间、文件类型和并发版本。

4. 过程检查
   助教可以查看各团队的提交进度，执行查收或退回操作，录入过程分并向未提交团队发送提醒。

5. 匿名同伴互评
   系统为学生分配其他团队的匿名成果，评分内容包括完成度、创新性和文档质量。互评支持草稿保存、匿名下载、极值剔除和异常评分预警。

6. 成绩管理
   系统按照互评分、过程分和终评分权重计算团队成绩，并结合个人系数、人工扣分和缺评扣分计算个人成绩。

7. 成绩发布与复核
   支持成绩发布、发布撤回、成绩快照、学生申诉、教务复核以及 CSV、Excel、PDF 格式导出。

8. 通知与审计
   支持截止时间提醒、催交通知、成绩通知和关键操作日志。审计日志采用 SHA-256 哈希链校验完整性。

9. 登录与权限安全
   系统对不同角色的数据访问范围进行隔离，连续五次登录失败后账号锁定十五分钟，写操作使用 CSRF 校验。

四、角色权限

1. 教务管理员
   查看全部课程项目，处理成绩复核，撤回成绩发布，导出成绩归档，校验审计日志并创建数据库备份。

2. 教师
   创建课程和项目，设置迭代与评分权重，管理团队成员，控制互评阶段，录入终评分，核定个人成绩并发布成绩。

3. 助教
   查看团队与成果，执行过程检查，录入过程分，发送催交通知并处理互评预警。

4. 学生
   创建或加入团队，审批入队申请，更新个人任务，提交成果，完成匿名互评，查看成绩并发起成绩复核。

五、运行环境

1. 操作系统：Windows 10 或 Windows 11，64 位。
2. Python：3.10 或更高版本。
3. Node.js：22.12.0 或更高版本，仅桌面版和桌面打包需要。
4. Python 运行依赖位于 backend\requirements.txt。
5. Python 测试依赖位于 backend\requirements-dev.txt。
6. Electron 依赖位于 desktop\package.json 和 desktop\package-lock.json。

六、启动方法

1. 双击项目根目录中的“启动系统.bat”。
2. 输入 1 启动网页版，浏览器访问 http://127.0.0.1:5080。
3. 输入 2 启动 Electron 桌面版。
4. 输入 3 安装或更新运行依赖。
5. 输入 4 检查本机环境。
6. 输入 5 运行自动化测试。
7. 输入 6 构建 Windows 便携版。
8. 系统运行期间需要保持启动窗口开启。

八、数据位置

1. 浏览器版数据库：backend\data\platform.db
2. 上传文件目录：backend\uploads
3. 桌面开发版数据：backend\data
4. 桌面发行版数据：Windows 用户应用数据目录中的 platform-data
5. 自动化测试使用临时数据库，不修改正式运行数据。

九、自动化测试

完整测试包括 33 项后端与业务接口用例，以及 28 项前端浏览器页面用例，共 61 项。测试覆盖登录认证、角色权限、数据隔离、项目发布、团队管理、成果提交、匿名互评、过程评分、成绩发布、成绩复核、导出和审计等功能。

完整测试命令：

python .\tests\test_script.py --mode all

测试日志、运行结果和页面截图保存在 tests\screenshots，固定版测试报告位于 tests\TEST_REPORT.pdf。

十、项目目录

backend      Flask 后端、数据库初始化和后端接口测试
frontend     登录页、工作台、业务页面和样式资源
desktop      Electron 桌面端和 Windows 打包脚本
tests        完整测试脚本、测试报告、日志和页面截图
docs         设计资料和界面效果图片
tools        Windows 启动菜单和统一运行脚本
高校课程项目协作设计报告.md    系统类设计、体系结构和接口设计

十一、运行说明

1. 端口 5080 被占用时，需要先关闭占用该端口的本地服务。
2. desktop\node_modules 为本地生成的依赖目录，可通过 npm install 重新安装。
3. backend\data 和 backend\uploads 为运行时目录，由系统首次启动时自动创建。
4. frontend\assets 中的图片为登录页面和界面运行资源。
